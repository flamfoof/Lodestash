06 · PROCEDURAL GRAPHICS (no asset files)
The remaining "graphics" in the prototype are drawn at runtime, not stored images. Recreate them the same way in egui rather than shipping bitmaps:
  • Thumbnail placeholders — per-asset HSL swatches (each asset carries hue/sat); models/images render a tinted gradient tile, sounds a waveform of bars. In the app these are the real decoded previews at the chosen on-screen quality.
  • Size-tier & type diamonds — small rotated CSS squares colored by tier/type token.
  • Toggles, chips, progress & usage bars, the file-size threshold track — pure layout + fills from theme.rs tokens.
  • Wordmark — set in Cinzel; no logo image is used.
Real icon source of truth: docs/design/icons.svg (see DESIGN-GUIDELINES.md §5). Colors: map each swatch to the theme.rs token named in the main handoff README's token table.
